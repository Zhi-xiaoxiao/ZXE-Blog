从零开始搭建 Flask Web 应用指南

发布日期：2026-09-12 | 标签：技术

在 Python 的 Web 框架中，Flask 以其“微框架”（Microframework）的特性脱颖而出。它没有 Django 那样沉重的内置组件，而是提供了极高的灵活性和自由度，非常适合快速构建轻量级 API 或中小型 Web 应用。

今天，我将记录从零开始搭建一个 Flask 项目的核心步骤与最佳实践。

1. 环境准备

在开始之前，强烈建议使用虚拟环境来隔离项目依赖，避免不同项目之间的包版本冲突。

# 创建项目文件夹并进入
mkdir my_flask_app && cd my_flask_app

# 创建虚拟环境 (Windows)
python -m venv venv
# 创建虚拟环境 (macOS/Linux)
python3 -m venv venv

# 激活虚拟环境 (Windows)
venv\Scripts\activate
# 激活虚拟环境 (macOS/Linux)
source venv/bin/activate

2. 安装 Flask

在激活的虚拟环境中，使用 pip 安装 Flask：

pip install flask

建议顺手生成依赖文件，方便后续部署：

pip freeze > requirements.txt

3. 编写第一个应用

在项目根目录下创建一个名为 app.py 的文件，写入以下最基础的代码：

from flask import Flask

# 初始化 Flask 应用
app = Flask(__name__)

# 定义路由和视图函数
@app.route('/')
def hello_world():
    return "Hello, Flask! 这是我的第一个 Web 应用。"

# 启动应用
if __name__ == '__main__':
    # debug=True 会在代码修改后自动重启，并提供详细的错误页面
    app.run(debug=True, port=5000)

4. 运行与调试

在终端中运行该文件：

python app.py

你会看到类似这样的输出：

 * Serving Flask app 'app'
 * Debug mode: on
 * Running on http://127.0.0.1:5000

打开浏览器访问 http://127.0.0.1:5000，就能看到你的网页了！

5. 推荐的项目结构

虽然 Flask 很灵活，但随着项目变大，将所有代码塞进一个文件是灾难。推荐采用以下基础结构：

my_flask_app/
├── venv/                 # 虚拟环境目录 (不要上传到 Git)
├── app.py                # 应用入口文件
├── requirements.txt      # 依赖列表
├── templates/            # 存放 HTML 模板文件 (Jinja2)
│   └── index.html
└── static/               # 存放静态文件 (CSS, JS, 图片)
    └── style.css

6. 下一步探索

  • 模板渲染：学习使用 render_template 返回动态 HTML。
  • 数据库集成：引入 Flask-SQLAlchemy 进行数据持久化。
  • 表单处理：使用 Flask-WTF 安全地处理用户输入。
  • RESTful API：使用 Flask-RESTful 或原生方法构建前后端分离的接口。

总结

Flask 的魅力在于“按需扩展”。它给了你坚实的基石，而如何构建大厦，完全由你决定。希望这篇指南能帮你顺利迈出 Flask 开发的第一步！
