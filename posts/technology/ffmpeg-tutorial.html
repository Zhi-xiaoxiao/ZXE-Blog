FFmpeg 极简实战教程：音视频处理的瑞士军刀

发布日期：2026-09-15 | 标签：技术

在音视频处理领域，FFmpeg 是当之无愧的王者。无论是格式转换、视频裁剪、提取音频，还是压缩体积、添加水印，它都能通过几行简单的命令行轻松搞定。今天我们就来掌握这把“瑞士军刀”的核心用法。

1. 安装 FFmpeg

  • Windows：前往官网下载 Build 版本，解压后将 bin 目录添加到系统环境变量 PATH 中。
  • macOS：使用 Homebrew 一键安装：brew install ffmpeg
  • Linux (Ubuntu/Debian)：使用 apt 安装：sudo apt install ffmpeg

安装完成后，在终端输入 ffmpeg -version，看到版本号即表示安装成功。

2. 核心语法逻辑

FFmpeg 的命令结构非常直观，基本遵循以下公式：

ffmpeg [全局参数] -i [输入文件] [处理参数] [输出文件]
💡 核心原则：FFmpeg 是“基于扩展名”工作的。你只需要告诉它输入是什么，输出文件名是什么扩展名，它会自动选择合适的编码器进行转换。

3. 高频实战命令

① 格式转换（最基础）

将 MP4 视频转换为 MKV，或者将 MP3 转换为 WAV：

ffmpeg -i input.mp4 output.mkv
ffmpeg -i audio.mp3 audio.wav

② 提取视频中的音频

只需要音频流，不需要视频画面（-vn 表示 no video）：

ffmpeg -i video.mp4 -vn -acodec mp3 audio.mp3

③ 裁剪视频片段

从第 10 秒开始，截取时长为 5 秒的片段（-ss 是开始时间，-t 是持续时间）：

ffmpeg -i input.mp4 -ss 00:00:10 -t 5 -c copy output.mp4

注：-c copy 表示直接复制流而不重新编码，速度极快，但裁剪点可能不是关键帧导致有误差。如果需要精确裁剪，去掉 -c copy 即可。

④ 压缩视频体积

通过降低码率（-b:v）和分辨率（-s）来减小文件大小：

# 将视频宽度压缩为 1280，高度自动按比例缩放
ffmpeg -i input.mp4 -vf scale=1280:-1 -b:v 1000k output.mp4

⑤ 调整视频播放速度

将视频加速 2 倍（setpts 调整视频，atempo 调整音频）：

ffmpeg -i input.mp4 -vf "setpts=0.5*PTS" -af "atempo=2.0" output.mp4

⑥ 合并多个视频片段

首先创建一个文本文件 list.txt，内容如下：

file 'part1.mp4'
file 'part2.mp4'
file 'part3.mp4'

然后执行合并命令：

ffmpeg -f concat -safe 0 -i list.txt -c copy output.mp4

⑦ 为视频添加图片水印

将水印图片放在视频的右下角（距离边缘 10 像素）：

ffmpeg -i input.mp4 -i watermark.png -filter_complex "overlay=W-w-10:H-h-10" output.mp4

4. 实用小技巧

  • 查看文件信息：不想处理，只想看视频的编码、分辨率、时长？使用 ffprobe input.mp4。
  • 截取一张封面图：提取视频第 5 秒的画面作为 JPG 图片：ffmpeg -i input.mp4 -ss 00:00:05 -vframes 1 cover.jpg
  • 批量处理：FFmpeg 本身不支持批量，但可以结合 Shell 脚本或 Python 的 subprocess 模块轻松实现批量转码。

总结

FFmpeg 的参数多达数百个，但日常开发和使用中，掌握上述 20% 的核心命令就能解决 80% 的问题。建议将常用的命令保存为脚本或别名（Alias），能极大提升你的工作效率。
