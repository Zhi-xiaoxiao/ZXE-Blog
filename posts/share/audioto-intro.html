开源分享：Audioto —— 一款极简的 GUI 音频转码工具

发布日期：2026-08-27 | 标签：分享

在日常工作和生活中，我们经常需要将音频文件在不同的格式之间进行转换。虽然网上有很多在线转换工具，但往往伴随着文件大小限制、上传隐私风险或繁琐的广告。

为了解决这个痛点，我开发并开源了一款基于 Python 和 PySide6 的极简桌面端音频转码工具 —— Audioto。

✨ 核心功能特性

  • 主流格式支持：完美支持 MP3, WAV, FLAC, AAC, OGG 等常见音频格式的互相转换。
  • 高度自定义：支持自定义输出目录，并可自由设置默认输出码率（默认 192kbps，兼顾音质与体积）。
  • 实时反馈：内置实时进度条显示与详细的状态提示，转码过程一目了然。
  • 极简设计：界面干净直观，没有多余的复杂选项，真正做到“开箱即用”。

📦 如何获取与使用

为了照顾不同技术背景的用户，Audioto 提供了两种使用方式：

方式一：直接运行（推荐普通用户）

我已经将程序打包为独立的 .exe 可执行文件（内置了 ffmpeg），无需安装任何环境，下载后双击即可直接运行。

方式二：源码运行（推荐开发者）

如果你想查看源码或参与贡献，可以通过以下方式在本地运行：

  • 确保已安装 Python 3.8+
  • 安装依赖：pip install PySide6
  • 下载 ffmpeg，并将 ffmpeg.exe 放置在程序同级目录下
  • 运行主程序脚本即可启动 GUI 界面
